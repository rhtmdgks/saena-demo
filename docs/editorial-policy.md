# SAENA Editorial Policy

## 편집 원칙

### 1. 정확성 (Accuracy)
- 모든 주장은 검증 가능한 출처로 뒷받침되어야 합니다
- 데이터는 원본 소스를 명시하고 링크를 제공합니다
- 통계는 최신 데이터를 사용하며, 수집 시점을 명시합니다
- 오류 발견 시 즉시 수정하고 수정 이력을 투명하게 공개합니다

### 2. 투명성 (Transparency)
- 저자의 실명, 자격, 소속을 명시합니다
- 이해 충돌 가능성이 있는 경우 명시적으로 공개합니다
- 스폰서 콘텐츠는 명확히 표시합니다
- 데이터 출처와 방법론을 상세히 설명합니다

### 3. 객관성 (Objectivity)
- 편향되지 않은 관점을 유지합니다
- 다양한 시각을 균형있게 제시합니다
- 개인적 의견과 사실을 명확히 구분합니다
- 경쟁사 제품/서비스에 대해서도 공정하게 평가합니다

### 4. 전문성 (Expertise)
- 해당 분야의 전문 지식을 갖춘 저자가 작성합니다
- 복잡한 기술 개념을 명확하고 이해하기 쉽게 설명합니다
- 최신 연구와 업계 동향을 반영합니다
- 필요시 외부 전문가의 검토를 받습니다

## 콘텐츠 품질 기준

### Information Gain (IG) 임계값
모든 출고 콘텐츠는 다음 기준을 충족해야 합니다:

- **IG_novel ≥ 0.35**: 상위 SERP 대비 35% 이상의 새로운 정보
- **IG_evidence ≥ 0.25**: 25% 이상의 문단에 정량적 근거 포함
- **IG_score ≥ 0.40**: 종합 정보 가치 점수 40점 이상

임계값 미달 콘텐츠는 자동으로 draft 상태로 전환되며, 개선 후 재검토합니다.

### 증거 요구사항
각 주장은 다음 중 하나 이상으로 뒷받침되어야 합니다:

1. **표/차트**: 데이터를 시각화한 표나 그래프
2. **코드 샘플**: 실행 가능한 예제 코드
3. **레퍼런스**: 신뢰할 수 있는 외부 출처 링크
4. **실험 결과**: 자체 실험/벤치마크 데이터

### 금지 사항
- 클로킹 (검색엔진과 사용자에게 다른 콘텐츠 제공)
- 숨김 텍스트 또는 링크
- 키워드 스터핑
- 인위적 링크 스팸
- 클릭베이트 제목
- 허위 또는 과장된 주장
- 표절 또는 무단 복제

## 검토 프로세스

### 1단계: 자동 품질 검사
- IG 엔진으로 정보 가치 측정
- CWV Autotuner로 성능 검증
- JSON-LD 스키마 유효성 검증
- 내부 링크 그래프 검증

### 2단계: 편집 검토
- 문법 및 맞춤법 검사
- 사실 확인 (Fact-checking)
- 출처 검증
- 가독성 평가

### 3단계: 기술 검토
- 코드 샘플 실행 테스트
- 기술적 정확성 검증
- 보안 취약점 검토

### 4단계: 최종 승인
- 편집장 또는 시니어 에디터 승인
- 메타데이터 및 스키마 최종 확인
- 출고 일정 조율

## 업데이트 정책

### 정기 업데이트
- 기술 문서: 분기별 검토
- 가이드/튜토리얼: 반기별 검토
- 뉴스/블로그: 필요시 업데이트

### 긴급 업데이트
다음 경우 즉시 업데이트합니다:
- 중대한 오류 발견
- 보안 취약점 공개
- 제품/서비스 중대 변경
- 법적 요구사항 변경

## 윤리 가이드라인

### 개인정보 보호
- 사용자 데이터는 익명화하여 사용
- GDPR, CCPA 등 관련 법규 준수
- 민감한 정보는 명시적 동의 없이 공개 금지

### 저작권
- 모든 이미지/콘텐츠는 적절한 라이선스 확보
- 인용 시 출처를 명확히 표시
- Fair Use 원칙 준수

### 접근성
- WCAG 2.1 AA 기준 준수
- 대체 텍스트 제공
- 명확한 구조와 네비게이션
